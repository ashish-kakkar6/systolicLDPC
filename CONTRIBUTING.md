# Contributing

The repo is actively being developed is looking for contributors! Feel free to email me at ashish dot kakakr @ gmail dot com to discuss 
open problems and research directions. 
Open an issue with a clean scope.
Make sure the relevant example flow still works and that `make test` and `make docs` pass.
Keep new examples in the same `build.py -> run.py -> read.py` shape as the existing public flows.
Match the existing style of the surrounding example, RTL, and documentation files.
